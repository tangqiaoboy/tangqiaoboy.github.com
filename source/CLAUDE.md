# CLAUDE.md — 唐巧的博客写作规范

这是一个基于 **Hexo** 的个人博客（[blog.devtang.com](https://blog.devtang.com)），作者唐巧。本文件用于指导在 `_posts/` 中创作和修改文章。**先读本文件，再动手写。**

## 项目结构

- `_posts/` — 所有已发布文章（约 386 篇，本目录就在 `source/_posts/`）
- `images/` — 文章配图（`source/images/`），文章用 `/images/xxx.png` 引用
- `_drafts/` — 草稿
- `_archive/` — 归档
- 配置在仓库根 `../_config.yml`，模版在 `../scaffolds/`，作者中文名「唐巧」

## 文件命名规则

格式：`YYYY-MM-DD-english-slug.md`

- 日期前缀必须与 front matter 里的 `date:` 一致
- slug 用**英文或拼音**，全小写，单词间用 `-` 连接（kebab-case）
- 新文章一律用 `.md`。旧文章有 `.markdown` 后缀（约 111 篇），**不要批量改后缀**，改内容时保持原扩展名
- **系列文章**用数字后缀：`supply-chain-1.md`…`supply-chain-10.md`、`silicon-valley-1/2/3`、`swift-gym-1`…`6`、`option-learning-notes-1`…`4`

## Front Matter（YAML）

默认模版（`scaffolds/post.md`）只有三项：

```yaml
---
title: 中文标题
date: 2026-05-31 10:00:00
tags:
---
```

字段约定：

- `title:` — **中文**标题（规则见下）
- `date:` — `YYYY-MM-DD HH:mm:ss`，必须有
- `tags:` — 单值或列表两种写法都用：
  ```yaml
  tags: books          # 单值
  ```
  ```yaml
  tags:                # 列表
    - AI
    - Claude Code
  ```
- `categories:` — **可选**，近年文章常省略。仅在归类明确时用，主要取值：`summary`（读书/年度总结类，最常用）、`iOS`（旧技术文）、`shell`、`mac`、`AI`

常用 tag：`books`(读书笔记)、`cspj`(算法教学)、`anniversary`(周年/年度总结)、`supply-chain`、`startup`、`Swift`、`cooking`(菜谱)、`Git`、`AI`、`PM`、`Interview`。**优先复用已有 tag，不要造新词。**

| 系列笔记 | `系列名(N)：副标题` | `供应链笔记(1)：如何挑选供应商`；`理财学习笔记(2)：不懂不投` |

## 写作风格（核心约束）

1. **语言**：中文为主，**专业术语保留英文原词**（LLM、harness、context、token、function calling、DFS、STL、Agent Loop…），不强行翻译。
2. **盘古之白**：中文与英文/数字之间**加一个空格**。例：`69 公里 6 小时`、`8M 栈空间`、`2^10=1024 种`、`Claude Code 现在原生支持`。这是全站最显著的排版特征，务必遵守。
3. **标点**：中文正文用全角标点（，。：；""《》），行内英文/代码片段用半角。
4. **结论先行**：开头一两段先抛出核心观点或反直觉的事实，再展开论据。
5. **结构清晰**：用 `##` 二级标题分节，章节常带序号（`一、二、三` 或 `### 1.`）；结尾几乎总有 `## 小结` / `## 总结` / `## 结语`，给出个人感受或一句话提炼。
6. **强调手法**：关键句用 `> 引用块` 突出（高频）；关键术语用 `**加粗**`。
7. **第一人称、真诚坦率**：用「我」，敢于自我反思和承认不足（如年度总结里直言「没挣到钱」），不端着、不写成 SaaS 营销文案。

## 各类文章的内容结构

- **读书笔记**：开头一句话介绍书和作者（书名用 `[《书名》](豆瓣链接)`），按概念分 `##` 小节复述+消化要点，结尾 `## 小结` 写自己的收获。
- **算法教学**：先讲「模版/原理」，再用 markdown 表格列练习题（带[洛谷链接](https://www.luogu.com.cn/)），然后逐题给「解法 + 参考代码」。C++ 代码块顶部带 `Author: Tang Qiao` 注释，用 `#include <bits/stdc++.h>`。
- **技术文**：可放可运行的代码块（标语言：`​```python`、`​```c++`），配合分点拆解和失效场景讨论。
- **菜谱**：`## 一、食材准备` + `## 二、烹饪步骤`（分「第一步/第二步…」），用 `-`/`*` 列小贴士。
- **游记/年度总结**：叙事为主，年度总结常含 `## 工作`、`## 读书`、`## 个人 Milestone`、`## 未来` 等小节。

## 图片

- **优先**用 Hexo 标签：`{% img /images/filename.png %}`（全站 252 处用此写法，仅 21 处用 markdown 语法）
- 图片文件放 `source/images/`，命名与文章 slug 关联（如 `swift-gym-5-1.png`、`beijing-4ring-route.jpg`）
- 引用路径以 `/images/` 开头（绝对路径）

## 新建文章流程

1. 确认日期、类型，按上面规则定 slug 和中文标题
2. 在 `_posts/` 创建 `YYYY-MM-DD-slug.md`，写好 front matter（`title`/`date`/`tags`，按需加 `categories`）
3. 正文遵守上述风格约束，尤其是**盘古之白**和**结尾小结**
4. 配图放 `images/` 并用 `{% img %}` 引用
5. 数据/观点注明来源（书名带豆瓣链接、题目带洛谷链接、引用项目带 GitHub 链接）
